## 목적 및 톤

YORBI는 *Born Curious. Built to Evolve.* — AI 시대에 태어난 작은 디지털 생명체. 타인이 관심을 갖도록 만든 가짜 거래량이나 확정되지 않은 상장 소식 대신, **세계관·성장 기록·유용한 기능·투명한 과정**을 꾸준히 제공합니다.

- 목소리: 호기심 많고 장난스럽지만 사실관계는 매우 엄격하게.
- 실제로 제공하지 않는 AI 상담·에이전트·보안 감사·토큰 유틸리티를 제공한다고 주장하지 않기.
- 영문 단일 포스트를 기본 초안으로 활용하되 필요하면 한국어 글로 별도 발행. 한 게시글에 무리하게 두 언어를 모두 넣지 않기.
- 가격 목표(10x/100x), 수익 보장, 허위 CEX 상장, fake token CA, 지갑 DM 수집, 무단 투자 권유 금지.
- 공식 토큰 주소가 없을 때 주소를 게시하지 않음. 발행 후라면 체인과 공식 Explorer 증거를 먼저 교차 검증.

## 최초 12~15개 게시 이후 유지 관리

- 정해진 콘텐츠가 없으면 매일 억지로 올리지 않습니다. **주 2~3개 제작/탐험 업데이트**와 **주 1개 투명성 보고**를 기본 *초안 목표*로 제안합니다. 실제 인력/반응에 따라 조절합니다.
- 매주 15~30분: 답변이 필요한 댓글 확인, 사칭 링크 차단, 개발 이슈/피드백 수집, 다음 게시 검수.
- 월 1회: 게시물 반응(실제 질문/재방문/유용한 참여), GitHub 릴리스, 커뮤니티 불편사항 확인. 팔로워 구매/가짜 리트윗 금지.
- 유료 홍보, 타 프로젝트 협업, 인플루언서 게시 계약은 이해관계 및 광고 여부를 명시합니다.
- 시장 변동·코인 가격을 홍보 콘텐츠의 핵심 KPI로 사용하지 않습니다. 캐릭터의 실제 성장과 공동체 기여가 주요 KPI입니다.

## 모든 게시물의 발행 전 체크리스트

- [ ] 문장의 날짜·현재 상태·토큰 존재 여부가 **실제 최신 자료**와 일치
- [ ] X 무료 계정에서 글자수 제한(링크, Unicode 포함) 및 게시 후 수정 제약 확인
- [ ] 실제로 공개한 기능/코드/스크린샷에 근거한 표현만 사용
- [ ] 향후 계획(Planned), 베타(Beta), 실제 운영(Live)을 구별
- [ ] URL, 공식 계정, Chain+Contract(발행 후), 해시가 정확함
- [ ] 수익 보장·가짜 제휴·공격적 구매 유도·시세조종 뉘앙스 없음
- [ ] 사칭 주소·민감정보·지갑 키·개인정보가 들어 있지 않음
- [ ] 같은 주제로 중복 게시 여부 확인
- [ ] 영어/한국어 오탈자 검토, 사용자 최종 승인 후 게시
