A name isn't an identity.

Different tokens can use the same name or ticker. The chain and full contract address matter far more than a symbol.

YORBI's field note

A token lookup should use the pair of chain ID and token address, not simply a ticker. Always verify the contract independently before interacting.

11 OCT 2026 MARKET BASICS

Liquidity isn't a promise.

A pool's quoted liquidity is useful context. It does not mean you can sell a large position at the last displayed price.

YORBI's field note

DEX data describes each pair, not guaranteed execution. Pool depth, trade size and fees can change your actual proceeds.
